## Struktur folder

| Folder | Isi |
|---|---|
| `00_Materi/` | Materi/ketentuan TB dari dosen |
| `01_Dataset/raw/` | Dataset asli sebelum preprocessing (.csv) + catatan sumber/lisensi |
| `01_Dataset/processed/` | Dataset hasil preprocessing (.csv), diekspor dari Orange |
| `02_Orange_Workflow/` | File workflow Orange (.ows) |
| `03_Visualisasi/` | Export grafik dari Orange + screenshot workflow (untuk laporan & lampiran) |
| `04_Laporan/` | Draft laporan (.docx) |
| `05_Presentasi/` | Slide presentasi Pertemuan 14 & 15 |
| `06_Referensi/` | Jurnal/artikel untuk daftar pustaka (APA 7) |
| `Final_Submit/` | File final yang diupload ke Classroom |

## Checklist pengumpulan (Final_Submit)

- [ ] `TB Big Data Kelompok X.docx`
- [ ] Workflow Orange `.ows`
- [ ] Dataset sebelum preprocessing `.csv` (jika lisensi mengizinkan)
- [ ] Dataset sesudah preprocessing `.csv` (jika lisensi mengizinkan)

## Standar minimum laporan

- [ ] ≥ 3 pertanyaan analisis
- [ ] ≥ 3 visualisasi
- [ ] ≥ 3 insight
- [ ] ≥ 2 rekomendasi untuk stakeholder
- [ ] Penjelasan keterbatasan dataset & analisis
- [ ] Lampiran: screenshot workflow Orange, dokumentasi dataset, pembagian kerja
